# JoosAtlas v6 — GitHub 교체 방법

## 구성

- `index.html` — JoosAtlas 메인 홈페이지
- `case-001.html` — 논문 Case 001 해설 페이지
- `styles.css` — 공통 디자인
- `app.js` — 모바일 메뉴와 C3/R3/D3 증거 탐색기
- `assets/` — 현장사진, 결과도, 로고, 이론 도식
- `docs/` — 공개범위와 배포 기록

## 게시 순서

1. `JoosAtlas_v6_GitHub_Deploy.zip`을 다운로드하고 압축을 풉니다.
2. GitHub의 `JoosAtlas` 저장소에서 기존 파일을 정리합니다.
3. **Add file → Upload files**를 누릅니다.
4. 압축을 푼 폴더 안의 모든 파일과 폴더를 업로드합니다.
5. Commit summary에 `Publish JoosAtlas v6 research studio`를 입력합니다.
6. **Commit directly to the main branch**를 선택하고 커밋합니다.
7. 1–3분 후 아래 주소에서 `Ctrl + F5`로 확인합니다.

https://daejinpipero-gaja.github.io/JoosAtlas/
