Case 001과 소개 페이지의 **본문은 고치지 않았습니다.** 그 두 페이지의 `Updated 7 August 2026` 표기도 그대로 두었습니다.

덤으로 v11의 휴대폰 화면 결함 하나를 고쳤습니다. Case 001을 영어로 휴대폰에서 열면 그래프 카드와 데이터 표가 화면 오른쪽으로 39px 넘쳤습니다. 이제 카드는 화면 폭에 맞고, 표는 제 칸 안에서 옆으로 밀어 봅니다.

## 2. 올리는 법

1. 묶음 파일의 압축을 풉니다.
2. 저장소 `daejinpipero-gaja/JoosAtlas`에서 **Add file → Upload files**를 엽니다.
3. 압축을 푼 폴더 **안의 내용물 전체**를 끌어다 놓습니다. 폴더째가 아니라 그 안의 파일과 폴더들입니다. 같은 이름의 파일은 새 것으로 바뀌고, 폴더 구조는 그대로 유지됩니다.
4. Commit changes를 누릅니다.
5. 1~2분 뒤 <https://daejinpipero-gaja.github.io/JoosAtlas/> 에서 확인합니다.

영상 파일이 15MB라서 올리는 데 시간이 조금 걸립니다. 파일 하나의 한도는 25MB입니다.

## 5-1. 한국어 전환

헤더의 `한국어` 단추를 누르거나 키보드에서 `L` 을 누르면 사이트 전체가 한국어로 바뀝니다. ⌘K 팔레트에도 항목이 있습니다. 선택은 기억되며, 브라우저 언어가 한국어인 사람이 처음 들어오면 한국어로 열립니다.

바뀌는 범위는 화면에 보이는 글자 전부입니다. 제목과 본문뿐 아니라 그래프의 축 이름과 범례, 마우스를 올렸을 때 나오는 값, 감도 실험실의 상태 표시, 명령 팔레트, 그리고 이미지의 대체 텍스트까지 포함합니다. 동시에 `<html lang>` 이 바뀌므로 화면낭독기와 외부 번역 도구도 올바르게 동작합니다.

### 한국어 문구를 고치고 싶을 때

머리띠, 꼬리말, 검색창과 v11까지의 페이지는 `joosatlas-i18n.js` 파일 하나만 열면 됩니다. 왼쪽이 영어, 오른쪽이 한국어입니다. (v12에서 새로 만든 페이지의 본문은 그 페이지 안 `data-ko="…"`에 있습니다. `docs/CONTENT_GUIDE_KR.md` 5번 참고)

```js
"Research that survives contact with the field.":"현장을 견디는 연구.",
```

**오른쪽만 고치십시오.** 왼쪽은 페이지의 영어 문장과 글자 하나까지 같아야 하며, 다르면 그 문장은 번역되지 않습니다.

이 파일에 없는 것 — 숫자, 단위, 기호, 이메일 주소, `RMSE`, `ACERS`, `Yonghoe JOO` — 은 두 언어에서 똑같이 보이도록 일부러 뺐습니다.

새 문장을 추가한 뒤에는 다음으로 누락을 확인할 수 있습니다.

```
python3 -m http.server 8899
node tools/lang_audit.mjs
```

한국어로 열었을 때 아직 영어로 남아 있는 글자가 하나라도 있으면 그 문장을 그대로 출력합니다. 현재 상태는 **화면에 보이는 418개 문장 전부 번역 완료**입니다.

## 5-2. v10.1에서 바뀐 것

- **이름 표기**를 `Yonghoe JOO`(이름 먼저, 성은 대문자)로 통일했습니다. 프로필에는 `주용회`를 나란히 표기하고, 구조화 데이터에는 `givenName` / `familyName`을 따로 넣어 검색엔진과 인용 도구가 순서를 착각하지 않게 했습니다.
- **3인칭 문장을 1인칭으로** 모두 바꿨습니다. 자기 홈페이지에서 "He is also President of…"는 보도자료처럼 읽힙니다. 자화자찬으로 읽힐 수 있는 단어(rigorous 등)와 구호형 제목도 뺐습니다. 첫 문장은 이제 "I work between a laboratory and an industrial yard."이고, 아직 끝나지 않은 일은 끝나지 않았다고 적었습니다.
- **연락처**를 프로필 하단, 모든 페이지 푸터, ⌘K 팔레트 세 곳에 넣었습니다. (`daejinpipero@yonsei.ac.kr`, `daejinpipero@gmail.com`)
- **인물과 심벌이 잘리던 문제**를 구조적으로 고쳤습니다. 강연 사진은 635×710의 거의 정사각형이라 가로로 넓은 배경으로 쓰면 머리가 잘리고 연단의 연세대 엠블럼도 사라집니다. 이제 원본 비율 그대로 자체 프레임 안에 놓고 글은 옆에 둡니다. 전면 사진 섹션은 900px 이하에서 사진과 글을 위아래로 분리하고, 넓은 화면에서는 글을 인물 반대편에 배치합니다.

## 5-3. 구도 자동 검사

레이아웃을 고친 뒤에는 눈으로만 보지 말고 검사기를 돌리십시오. 네 페이지를 1440 / 1180 / 834 / 390 px에서 실제로 렌더링한 다음, 브라우저가 수행한 `object-fit: cover` 잘라내기를 그대로 다시 계산해서 보호 영역(머리, 연세대 엠블럼, 상반신, 용접공과 불꽃, 사옥과 파이프 야드)이 화면 밖으로 나갔는지 판정합니다. 이어서 렌더링된 픽셀에 얼굴 검출과 템플릿 매칭을 돌려 머리 위 여백과 엠블럼 존재를 눈이 아니라 수치로 확인합니다.

```
python3 -m http.server 8899
node tools/visual_audit.mjs
```

현재 상태는 **108개 검사 전부 통과**입니다. 자세한 사용법은 `tools/README.md`에 있습니다.

## 6. 값이 바뀌면 함께 고쳐야 하는 곳

수치를 한 곳만 고치면 다른 곳과 어긋납니다. 아래 세 곳은 항상 같이 보십시오.

| 값 | 위치 |
|---|---|
| C3 / R3 / D3 의 RMSE · 평균 · 최대 · 점 개수 | `joosatlas-v10.js` 상단 `TS` 배열, `case-001.html`의 잔차 표, 그리고 `assets/data/ts_summary.json` |
| 7 / 9 / 12 m 의 mm/px 값 | `joosatlas-v10.js` 상단 `RANGES` 배열, `case-001.html`의 곡선 표와 범례, `index.html`의 설명문 |
| ΔR 부호 해석 | `case-001.html`의 「Algebraic sign of the displayed definition」 표 |
| 한국어 문구 | `joosatlas-i18n.js` (오른쪽 값만 수정) |

**부호 규약은 최종 게재 원고와 반드시 일치해야 합니다.** 원고에서 뺄셈 순서가 바뀌면 사이트의 부호 설명도 함께 뒤집어야 합니다.
