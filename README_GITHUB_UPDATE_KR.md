# JoosAtlas v7 GitHub 게시 방법

현재 공개 주소:

`https://daejinpipero-gaja.github.io/JoosAtlas/`

## 교체 절차

1. 배포 ZIP을 다운로드하고 압축을 풉니다.
2. GitHub에서 `daejinpipero-gaja / JoosAtlas` 저장소를 엽니다.
3. **Add file → Upload files**를 누릅니다.
4. 압축을 푼 폴더 안의 파일과 폴더를 모두 선택해 업로드합니다.
5. Commit summary에 다음을 입력합니다.

   `Publish JoosAtlas v7 editorial rebuild`

6. **Commit directly to the main branch**를 선택합니다.
7. **Commit changes**를 누릅니다.
8. 1–3분 뒤 공개 주소를 열고 `Ctrl + F5`를 눌러 강제 새로고침합니다.
