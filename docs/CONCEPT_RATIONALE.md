# JoosAtlas Rebuild v3 — Concept Rationale

## Core proposition
The site is built around one conflict: a line may be visible before a measurement claim is justified.

## Original interactions
1. Evidence Lens — reveals an independent audit layer beneath the image layer.
2. Chain of Custody — separates datum, image, reference, and audit roles.
3. Claim Gate — permits a claim only when observability, geometric consistency, and terminal validity are all satisfied.
4. Failure Atlas — treats refusal and failure modes as first-class research outcomes.

## Visual direction
- field reconstruction instead of generic abstract circles
- restrained editorial typography
- instrument-derived grid and crosshair language
- teal = validated evidence
- amber = observation / attention
- red = conflict / refusal
- ivory = evidence surface
