# GitHub Pages deployment

1. Unzip the deploy package.
2. Open the `JoosAtlas` GitHub repository.
3. Choose **Add file → Upload files**.
4. Upload every file and folder from the unzipped package root.
5. Commit directly to `main`.
6. GitHub Pages is already configured for `main / (root)`; allow 1–3 minutes for deployment.
7. Hard-refresh the live page with `Ctrl + F5`.

Live URL:

https://daejinpipero-gaja.github.io/JoosAtlas/

For the repository social preview, upload `assets/images/social-preview.jpg` under **Settings → General → Social preview**.
