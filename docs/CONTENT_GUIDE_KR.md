# 새 자료 올리는 법 (v12부터)

JoosAtlas는 이제 자료를 계속 받아들이는 구조입니다. 새 자료를 하나 올릴 때 손댈 곳은 **파일 한 묶음과 등록부 한 칸**입니다. 홈 색인, 자료실 목록, 검색(⌘K)은 등록부를 읽어서 스스로 갱신됩니다.

## 1. 구조 한눈에

```
index.html               홈
library.html             자료실 (전체 목록)
case-001.html            연구 001                 ← 연구는 case-번호.html
thesis-2023.html         석사논문 풀어 읽기        ← 논문은 thesis-연도.html (영상 001이 이 안에 있음)
manual-001/              현장 교재 001 (여러 파일) ← 교재·도구는 폴더째로
media/film-001/          영상 파일과 포스터 이미지
assets/images/           사진, 표지 이미지
joosatlas-library.js     등록부 (자료 목록의 원본)
joosatlas-i18n.js        한국어 사전 (머리띠·꼬리말·검색창 문구)
```

번호는 종류마다 따로 셉니다. 연구 `001, 002…`, 교재 `M·001, M·002…`, 영상 `F·001, F·002…`.

## 2. 등록부에 한 칸 추가하기

`joosatlas-library.js`를 열면 `items: [` 아래에 자료가 블록 단위로 놓여 있습니다. 기존 블록 하나를 복사해 고치면 됩니다.

```js
{
  id:'film-002', kind:'film', code:'F·002', href:'film-002.html',
  state:'open', date:'2027-01-15', home:true,
  title:  { en:'English title', ko:'한국어 제목' },
  line:   { en:'One sentence.', ko:'한 문장 소개.' },
  status: { en:'Open', ko:'공개' },
  meta:   { en:'1 min 40 s · vertical 9:16', ko:'1분 40초 · 세로 9:16' },
  content:{ en:'Korean, captioned', ko:'한국어 · 자막' },
  thumb:'media/film-002/thumb.webp',
  poster:'media/film-002/poster.jpg',
  video:'media/film-002/film-002.mp4',
  duration:'1:40',
  alt:    { en:'What the picture shows.', ko:'그림이 보여 주는 것.' },
  keys:'검색에 걸릴 낱말들 keywords'
},
```

| 항목 | 뜻 |
|---|---|
| `kind` | `research` 연구 · `manual` 현장 교재 · `film` 영상 · `lab` 실험 · `tool` 도구 |
| `href` | 열리는 주소. **아직 공개하지 않은 자료는 이 줄을 빼면** 목록에 이름만 흐리게 나옵니다. |
| `state` | 이름표 색. `open` 공개 · `review` 심사 중 · `building` 개발 중 · `planned` 계획 |
| `status` | 이름표에 실제로 적히는 글. 확인하지 못한 부분이 있으면 여기에 적습니다. |
| `home:true` | 홈의 ‘현장 자료’ 구역에 액자로 겁니다. 영상은 세로 액자, 나머지는 가로 액자입니다. 두세 점이 적당하니, 새 것을 걸면 오래된 것에서 이 줄을 뺍니다. |
| `thumb` | 자료실 목록의 작은 그림. 4:3, 가로 800px 안팎 |
| `cover` | 홈 가로 액자의 큰 그림. 가로 1600px 안팎 |
| 맨 위 `updated` | 자료실의 ‘최근 추가’ 날짜. 자료를 올린 날로 고칩니다. |

## 3. 영상 하나 올리기

1. `media/film-002/` 폴더를 만들고 세 파일을 넣습니다.
   - `film-002.mp4` — H.264 영상, AAC 음성. **25MB 이하**(GitHub 웹 올리기 한도).
   - `poster.jpg` — 재생 전 화면에 보일 장면 한 컷.
   - `thumb.webp` — 목록용 4:3 그림.
2. 영상이 들어갈 페이지를 정합니다. 영상 001은 따로 페이지를 두지 않고 그 영상이 설명하는 석사논문 페이지(`thesis-2023.html`) 맨 위에 넣었습니다. 독립된 영상이면 `thesis-2023.html`에서 맨 위 영상 구역과 **06 영상** 구역(장면 목록, 수치와 근거)만 남겨 `film-002.html`로 저장하고 내용을 고칩니다. 한국어는 영어 문장 옆 `data-ko="…"` 안에 있습니다.
3. 등록부에 한 칸을 추가합니다(위 2번).

영상의 **수치와 근거** 표는 이 사이트의 원칙을 영상에 적용한 것입니다. 영상이 말하는 수치마다 공개 문서를 찾아 옆에 놓고, 찾지 못한 것은 ‘영상의 표기’라고 적습니다. 확인하지 않은 것을 ‘근거와 일치’로 적지 않습니다.

## 4. 교재나 도구 올리기

여러 파일로 된 자료는 폴더째로 `manual-002/`처럼 올리고, 그 안의 `index.html`이 첫 화면이 되게 합니다. 폴더 안에서 사이트의 다른 페이지로 가는 링크는 `../index.html`처럼 한 단계 위를 가리켜야 합니다. `manual-001/index.html`의 맨 위 머리띠와 맨 아래 꼬리말을 그대로 옮겨 쓰면 사이트의 일부로 읽힙니다.

## 5. 한국어 문구는 두 군데에 있습니다

- **머리띠, 꼬리말, 검색창**처럼 모든 페이지에 공통인 글자: `joosatlas-i18n.js` 사전. 왼쪽이 영어, 오른쪽이 한국어입니다.
- **새 페이지의 본문**: 그 페이지 안에 함께 적습니다.

```html
<p data-ko="한국어 문장">English sentence</p>
```

영어가 본문이고 한국어가 `data-ko`입니다. 이 방식의 글이 들어 있는 구역에는 바깥 요소에 `class="no-i18n"`을 붙여 사전 번역기가 건드리지 않게 합니다. 새 자료를 올릴 때 사전을 고칠 일은 거의 없습니다.

## 6. 올리기 전 점검

- [ ] **권리.** 직접 만들었거나 게시 허락을 받은 자료입니까. 다른 기관의 로고나 표기가 들어 있으면 허락 범위를 확인했습니까.
- [ ] **사람과 상호.** 손님의 상호, 얼굴, 차량 번호판이 보이지 않습니까.
- [ ] **연구 공개 범위.** `docs/PUBLIC_DISCLOSURE.md`에서 비공개로 정한 것(원좌표, 27개 조건 전체 결과, 캘리브레이션 파일, 심사 서신)이 섞이지 않았습니까.
- [ ] **이름표.** 확인하지 못한 수치나 조문이 있으면 `status`와 본문에 그렇게 적었습니까.
- [ ] **용량.** 파일 하나가 25MB를 넘지 않습니까.

## 7. 올린 뒤 고칠 곳

| 무엇 | 어디 |
|---|---|
| ‘최근 추가’ 날짜 | `joosatlas-library.js` 맨 위 `updated` |
| 홈 꼬리말의 갱신 날짜 | `index.html` 맨 아래 `Updated …` (새 날짜의 한국어는 사전에 한 줄 추가) |
| 검색엔진용 주소 목록 | `sitemap.xml`에 새 주소 한 줄 |
| 파일 목록과 체크섬 | `python3 tools/make_manifest.py` (선택) |
