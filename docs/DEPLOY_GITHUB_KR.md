# JoosAtlas GitHub Pages 게시 방법

현재 저장소: `https://github.com/daejinpipero-gaja/JoosAtlas`
공개 주소: `https://daejinpipero-gaja.github.io/JoosAtlas/`

## 교체 게시

1. ZIP을 내려받아 압축을 풉니다.
2. GitHub 저장소에서 **Add file → Upload files**를 누릅니다.
3. 압축을 푼 폴더 안의 파일과 폴더를 전부 선택해 올립니다.
4. `index.html`이 저장소 최상위에 보여야 합니다.
5. Commit summary에 `Publish JoosAtlas public profile update`를 입력합니다.
6. **Commit directly to the main branch**를 선택하고 커밋합니다.
7. 1–3분 뒤 공개 주소를 열고 `Ctrl+F5`로 강력 새로고침합니다.

## Pages 설정 확인

`Settings → Pages → Deploy from a branch → main → /(root)`

이미 위 설정이 되어 있다면 다시 건드릴 필요가 없습니다. 새 커밋이 자동 배포됩니다.

## GitHub 소셜 미리보기

`Settings → General → Social preview`에서 `assets/social-preview.png`를 업로드합니다.

## 공개범위

- 논문의 정확한 방법·수식·실험기하·수치결과·원자료는 포함하지 않습니다.
- 연구질문, 정성적 결과, 증거 중심의 연구철학, 연구자 소개만 공개합니다.
- JoosAtlas는 독립 개인 연구 플랫폼이며, 소속기관의 공식 견해를 대변하지 않습니다.
