# GitHub Pages Deployment

The ZIP is structured for direct upload to the repository root.

1. Open `https://github.com/daejinpipero-gaja/JoosAtlas`.
2. Select **Add file → Upload files**.
3. Upload every file and folder from the extracted package. `index.html` must be visible at the repository root.
4. Commit directly to `main` with the message: `Publish JoosAtlas public profile update`.
5. Open **Settings → Pages**.
6. Confirm **Deploy from a branch → main → /(root)**.
7. Wait for the green Pages deployment status.
8. Open `https://daejinpipero-gaja.github.io/JoosAtlas/` and hard-refresh with `Ctrl+F5`.
