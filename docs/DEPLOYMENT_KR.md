# GitHub Pages 교체 방법

1. ZIP을 압축 해제합니다.
2. GitHub의 `daejinpipero-gaja/JoosAtlas` 저장소에서 **Add file → Upload files**를 누릅니다.
3. 압축을 푼 폴더 안의 파일과 폴더를 모두 선택해 업로드합니다.
4. 커밋 메시지는 `Publish JoosAtlas v7 editorial rebuild`를 권장합니다.
5. `Commit directly to the main branch`를 선택하고 커밋합니다.
6. 1–3분 뒤 `https://daejinpipero-gaja.github.io/JoosAtlas/`에서 `Ctrl + F5`로 새로고침합니다.

GitHub Pages 설정은 이미 `main / (root)`이면 다시 변경하지 않습니다.
